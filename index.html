YouTube Data API 申請與使用完整教學

為什麼需要 YouTube API Key？

YouTube 官方對留言抓取有嚴格限制。透過您專屬的免費 API Key，本工具能直接串接官方 API，一鍵抓取破萬則留言且完全不會遺漏！

4 個步驟輕鬆取得免費 API 金鑰：

步驟 1

前往 Google Cloud Console 並登入您的 Google 帳號。

步驟 2

點擊頂部導覽列建立一個新專案（例如命名為 YT-Picker）。

步驟 3

在上方搜尋列搜尋 "YouTube Data API v3"，點進去並點擊藍色的 「啟用」 按鈕。

步驟 4

切換到左側選單的 「憑證 (Credentials)」，點擊上方的 「建立憑證」 ➔ 選擇 「API 金鑰 (API Key)」，即可複製您的專屬金鑰！

安全與額度提示：

  • 您的 API Key 僅會儲存在您自己的瀏覽器 LocalStorage 中，絕不會上傳至任何第三方伺服器。
  • YouTube Data API v3 提供免費額度（每日約 10,000 單位），足以應付數十萬則留言抓取。
